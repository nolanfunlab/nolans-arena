# Nolan's Arena

A Pokémon-themed chess game. Play against the computer and try to win!

Play it at [nolanfun.com](https://nolanfun.com).

## Features

- Three levels: Easy, Medium and Hard
- Save your game and load it later
- Export saved games to a file and import them on another computer

## Run it

Everything is in one file, so just open `index.html` in a browser.
